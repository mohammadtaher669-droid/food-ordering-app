حالياً بطاقات الأصناف تظهر بدون صور داخل المنيو، المطلوب إصلاح النظام بالكامل بحيث يتم عرض صور فعلية لكل الأصناف داخل الـ Cards مباشرة.

المشكلة الحالية:

* الصور لا يتم توليدها أو لا يتم ربطها بالبطاقات.
* يظهر Placeholder فقط بدل صور الطعام.

المطلوب:

* عند فتح المنيو:

  * النظام يتحقق من كل صنف.
  * إذا لم يكن للصنف صورة:

    * يقوم تلقائياً بتوليد صورة AI احترافية للصنف.
  * ثم:

    * يحفظ رابط الصورة داخل قاعدة البيانات.
    * يعرض الصورة مباشرة داخل Card الصنف.

المهم جداً:

* الصور يجب أن تظهر داخل:

  * Menu Cards
  * صفحة المنتجات
  * صفحة العميل
  * صفحة الطلبات
  * صفحة الكاشير

أضف نظام Auto Image Generation حقيقي يعمل تلقائياً لجميع الأصناف.

المطلوب تقنياً:

* عند إنشاء أو تعديل صنف:

  1. قراءة اسم الصنف
  2. قراءة الوصف
  3. قراءة التصنيف
  4. توليد Prompt تلقائي
  5. إرسال الطلب إلى AI Image API
  6. حفظ الصورة
  7. تحديث الواجهة مباشرة بالصورة الجديدة

مثال Prompt:
“Professional Arabic food photography of Bukhari Rice with grilled chicken, realistic, cinematic lighting, restaurant menu style, high quality”

المطلوب أيضاً:

* Bulk Generate Images لجميع الأصناف القديمة.
* زر Generate All Menu Images.
* Regenerate للصنف الواحد.
* Upload Manual Image.
* Edit Image URL.
* Lock Image لمنع تغييره.
* Preview للصورة.

أضف Queue System للتوليد:

* حتى لا يعلق الموقع.
* مع Progress Bar.
* وحالة لكل صنف:

  * Generating
  * Completed
  * Failed

إذا فشل التوليد:

* Retry تلقائي.
* استخدام Placeholder مؤقت.

المطلوب أن تكون الصور:

* Food Photography واقعية جداً.
* عالية الجودة.
* مناسبة لتطبيقات المطاعم.
* احترافية وملونة.
* بأبعاد مناسبة للبطاقات.

المهم جداً:

* تحديث الـ Frontend فوراً بعد توليد الصورة بدون Refresh.
* التأكد أن عنصر الصورة داخل الـ Card يستخدم:
  imageUrl أو generatedImageUrl بشكل صحيح.
* إصلاح أي مشكلة Mapping أو API أو Database تمنع ظهور الصور.

واستخدم:

* OpenAI Images API
  أو
* Stability AI
  أو
* Replicate

مع:

* Cloud Storage أو CDN.
* Cache لمنع إعادة التوليد لنفس الصنف.

وتأكد نهائياً أن جميع الأصناف داخل المنيو تعرض صور الطعام بشكل فعلي وليس Placeholder فارغ.
