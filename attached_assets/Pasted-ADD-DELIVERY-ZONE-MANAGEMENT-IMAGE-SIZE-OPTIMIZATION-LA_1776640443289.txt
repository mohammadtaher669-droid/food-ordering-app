ADD DELIVERY ZONE MANAGEMENT + IMAGE SIZE OPTIMIZATION + LARGE BANNER SYSTEM FOR OFFERS.

---

MAIN GOAL:

1. Allow admin to define delivery areas per branch
2. Improve menu item image sizes (medium, clear)
3. Add large promotional banners (hero sliders) per restaurant and homepage

---

1. DELIVERY ZONE SYSTEM (IMPORTANT)

FOR EACH BRANCH:

Add fields:

* delivery_type: ("radius" | "polygon")
* center_lat
* center_lng
* delivery_radius_km
* polygon_coordinates: [{lat, lng}]
* delivery_fee_rules (optional tiers)
* is_delivery_enabled (true/false)

---

ADMIN PANEL:

Create section:

"📍 Delivery Zones"

FEATURES:

A. MAP INTEGRATION:

* Use Google Maps or Leaflet
* Show branch location

B. TWO MODES:

1. RADIUS MODE:

* Admin selects center point
* Slider to choose radius (1km → 20km)
* Draw circle on map

2. POLYGON MODE:

* Admin draws custom area on map
* Save coordinates

---

C. VALIDATION:

* Customer location must be inside zone
* If outside:

Show:
"Delivery not available in your area / التوصيل غير متوفر في منطقتك"

---

D. CUSTOMER LOCATION:

* Ask for location (GPS or manual pin)
* Save temporarily

---

E. DELIVERY CHECK FUNCTION:

Create function:

isInsideZone(userLocation, branchZone)

Return true/false
